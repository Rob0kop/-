# РосПил — сайт партии на ИСР

Минималистичный статический сайт для публикации через GitHub Pages.

## Публикация на GitHub Pages
1. Создайте новый GitHub-репозиторий.
2. Загрузите `index.html`, папку `assets/` и `README.md` из этого архива.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

## Перед публикацией
- В `index.html` замените `https://discord.com/` на постоянную ссылку на сервер или канал партии.
- Проверьте формулировки программы и описания результатов под фактические события ИСР.
- Эмблема находится в `assets/emblem.png`.

## Содержимое
- `index.html` — адаптивный сайт.
- `assets/emblem.png` — предоставленная эмблема, увеличенная для более чёткого отображения.
